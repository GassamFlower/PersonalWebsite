## 0. 一句话气质

> v4 解决了「像不像好设计」，v5 要解决「**替不替我说话**」。
> 把 v4 的「档案陈列」升级为「**盖过章的档案**」：每个论点有批注轨（门状态/验证日期/证据指向），每个已验证成果盖一枚朱砂验收章。
> 两个新钉子：**有据 · 有章**（v4 的「冷 · 准」继续有效）。

## 1. 为什么需要 v5（v4 的三个缺口，诊断记录）

| 诉求 | v4 现状问题 | v5 对策 |
|---|---|---|
| 个性化 | 「墨水档案」是借来的 editorial 风格，任何个人站都套得上；本人真实世界（五门门禁/验证纪律）没有进入 UI | 把门禁纪律实体化为全站视觉装置（批注轨 + 验收章），模板不会这样说话 |
| 视觉感 | 张力全押在 Hero 3D 粒子上且是氛围型不表达论点；首屏之下均质灰白细线，无第二记忆点 | 粒子降级为背景；朱砂章制造受控的稀缺焦点；批注轨成为贯穿第二记忆点 |
| 说服力 | 「陈列」逻辑非「论证」逻辑；成果淹没在大段正文里 | 卡片统一 Claim→Evidence→Result 三段，结果行盖章节奏化呈现 |

> 诚实红线约束：不能靠夸大数字制造说服力，所以 v5 的说服力**全部来自编排与呈现结构**，不新增任何未验证声明。

## 2. 五项变更（本版唯二的新视觉元素：批注轨、朱砂章）

### 2.1 Signature：批注轨（Annotation Rail）

- 每个分区与关键卡片左缘一条 mono 批注轨，桌面为左缘窄列（约 10–11px mono），移动端降级为卡片顶部一行。
- 内容三选二，格式固定：`GATE✓ · 2026-08 · CASE/185`（门状态 / 验证日期 / 证据指向）。
- 编号语义：**五门是真序列**（立项→功能→架构→实现→上线），批注轨上的门标记只在内容确有对应门禁事实时出现——结构即信息，不做装饰性编号。
- 颜色：mono 灰（`--color-line`）为主，门状态词用墨蓝（`--color-accent`）。

### 2.2 朱砂验收章（Seal）＋ 对 v4 §8 的一处修订

- 新增 token `--color-seal: #C43C2B`（朱砂 · 印泥红），**全站唯一新增强调色**。
- 使用纪律（稀缺性即视觉感）：
  - 仅出现在 **Result 行 / 已验证成果** 上，形态为一枚小方形印章符（CSS/SVG 线框 + 「验」或日期），非色块铺底；
  - 每屏 ≤ 1 枚；全页合计 ≤ 6 枚；
  - **诚实分级绑定**：只有内容真源中标记为「已上线/已交付/已验证」的条目可盖章；「会用/在学/开发中」一律不盖（保持墨蓝描边徽章）。
- 与 v4 §8 的关系：v4 禁止「暖咖啡/金/橄榄回归」针对的是**装饰性暖色**；朱砂是**语义功能色**（印章/验收），且底色/主文字/识别色三大家族不动。此为对 v4 §8 的明确修订，仅放行朱砂一色，其余禁止条款全部保留。

### 2.3 Hero 从氛围改为立论（3D 仍限 Hero 一处，不违背换栈四决策）

- 背景层：现有三层浮尘粒子保留，降不透明度约 30%，纯氛围。
- 前景层：一张「档案卡」（白面 + 细线框 + 批注轨），内容为：
  1. 姓名 + 一句话身份论点（衬线，来自 content 真源，不新造文案）；
  2. 3 行 mono 事实行（如 `已上线 · 工程用车助手 · 2026-08`），其中已验证行可带朱砂章；
  3. 一个墨蓝实心入口（保留现有「精选作品」下划线入口逻辑）。
- 目标：访客 5 秒得到结论「这个人：系统化、有交付、可验证」；粒子负责情绪，档案卡负责论证。

### 2.4 证据链三段化（Claim → Evidence → Result）

- Cases 率先样板，其余区（CapabilityMap/Growth/Timeline 节点卡）后续同构铺开。
- 规格：
  - **Claim**：衬线一句论点（这是区块的标题层，回答「他能解决什么」）；
  - **Evidence**：无衬线正文（做了什么，现有文案复用，不重写内容）；
  - **Result**：mono 一行（结果/状态/日期）+ 批注轨 + 朱砂章（若已验证）。
- 混合受众各取所需：招聘方扫 Result 行，客户读 Claim，同行看 Evidence。
- 边界：三段是**版式重排**，不改 `src/content/` 的 md 内容与事实分级。

### 2.5 排版双轨 + 动效唯一新增点

- 字体家族不换（宋衬线/无衬线/IBM Plex Mono 三家族沿用 v4 §4），变的是**权力关系**：mono 从眉题配角升为「证据轨」正式成员（Result 行、批注轨、数据全部 mono）。
- 动效仅新增一处：**盖章微动效**。Result 行入视口时印章符 opacity 0→1、scale 1.15→1、rotate -3°→0，约 120ms，一次性播放；`prefers-reduced-motion` 下退化为纯淡入。其余动效维持 v4 克制基线（fade-up + 轻 hover）。

## 3. Token 增量（在 v4 token 之上仅加两行）

```css
--color-seal: #C43C2B;        /* 朱砂 · 验收章专用，纪律见 §2.2 */
--color-seal-faint: #F2E3DF;  /* 朱砂极浅底 · 仅印章符悬停底，可选 */
```

其余 v4 token（冷白纸/墨黑/墨蓝/深墨面板）**一律不动**。
