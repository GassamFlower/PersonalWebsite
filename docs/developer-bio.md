## 三、长版（400–600 字 · 适合完整个人介绍 / 平台详细资料）

> **我是谁**：独立系统构建者。能独立把团乱麻的需求，从零做成可运行、可交付、可上线的系统。8 年在真实政务系统里做业务与数据支持，日常与 SQL、数据口径、远程排障打交道，懂业务、懂数据、也见过真实场景里的坑。
>
> **做过什么**：
> - 工业运维平台 OPS（内部系统）：在工业企业里看到长期没人统一的设备与运维信息，从零搭成能查、能追、可诊断的平台，覆盖资产、监控、巡检、工单、安全、知识库与用户中心。
> - 统一用户中心 UUC（内部系统）：把多系统各自为政的账号、身份、权限收拢成一套统一入口、统一授权的企业 SSO 中台。
> - 工程用车助手（外单·已上线）：从谈需求到上线独立完成的小程序，把用车登记、审批、记录串成一条手机可查的流程，真实用户已在用。
> - 视频批量混剪 Web 平台（开发中）：把"一条条手工攒视频"的重体力，拆成字幕、贴片、转码均可批跑的流水线。
> - 真实工作场景里一批内部自动化/爬虫工具：日志自动化、文件自动分区、数据采集、网页自动化。
>
> **技能（诚实三档）**：
> - 前端（会用，均真实交付过）：Vue / React / Next.js / 微信小程序，响应式、数据看板、移动端优先。
> - 后端（会用）：Go 从零搭后台、接口与鉴权（含 SSO）。
> - 数据库（会用）：PostgreSQL、建表与业务表结构设计、SQL 报表与数据分析。
> - 数据采集与自动化（会用）：真实工作场景里的一批内部采集/效率工具。
> - AI 智能体与工具（会用，不称精通）：RAG / 知识库、智能体编排、Coze / Dify / n8n，AI 编程工具广泛实操。
> - 运维与部署（在学）：GitHub Pages 自动部署、后端服务部署实操、Linux / 网络基础。
> - 工程化与做事方法（已交付）：四门设计、单一信源 SSOT、五级项目体系、workLog 复盘机制。
>
> **怎么做事**：我有自己的一套做事规矩，也一直在公开成长、月度复盘。如果你有"内部数字化空白/数据乱/要一套系统"的需求，欢迎来聊——我能说清边界，也能诚实告诉你什么正在学。

- 不看粉丝数当业绩，看**私信与询价**——这是接单凭证站的唯一有效指标。
