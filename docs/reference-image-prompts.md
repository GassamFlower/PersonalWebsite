> 项目：Personal Website · 展示名「罗永贵」（网名，配角）
> 视觉方向：C+A（人文明亮 + 清晰体系），A类克制编辑为主 + B类点睛
> 出图规则：1 分区 = 1 张横向图；像真实网站截图，不是海报/幻灯片

## 生成后的审查（一致性 + 单调性 + 元素预算）

出图后执行：
1. **一致性**：导航/字标/配色/圆角/CTA 家族统一；分区顺序与节奏连贯；移动端可行性。
2. **单调性**：9 分区骨架是否重复（当前设计：偏左目录 / 左右分屏 / 四层 / 时间线 / 框线案例 / 编辑索引 / 编号索引 / 极简联系 / 极简页脚 —— 骨架各不相同）。灰块测试：至少一半分区去掉视觉后仍像"被设计过"。
3. **元素预算**：每区承载图像的面板 ≤ 1 主 + 2 chip；无重叠堆叠。

审查通过 → 用户确认作为构建目标 → 进架构门（Astro 骨架 + 设计 token）。
