## 0. 全局风格基准（先贴这条让平台锁定气质，再逐区出图）

```
一页个人品牌单页网站的设计方向。气质是"精品咨询 / 建筑事务所 / 工业设计工作室"——
克制、高级、可信、成熟，"贵但不装"。整站是一份"公开的个人档案 / 交付卷宗"。

配色 token（严格锁定）：
- 背景：骨白/暖灰白 #F2EFE9（微细石质/纸感噪点，opacity 极低，可省）
- 文字：近黑深灰 #1C1A17（不用纯黑 #000）
- 弱文字/细线：中性灰 #8A8580
- 主识别色：深橄榄绿 #4A5A3A（全站唯一识别色，克制使用）
- 强调色：铜棕/暗金 #8B6F47（极少量点睛，每屏不超过 1-2 处）

字体：标题用巨大衬线 Serif（思源宋体/Noto Serif SC 超粗字重，editorial 建筑感）；
正文用现代无衬线（思源黑体/Noto Sans SC）；档案编号/年份/日期用等宽字体。
排印：大留白，标题可到 viewport 极大比例；统一编号卷宗眉题（如"档案 01 · 定位"）。

布局：严格 12-column 栅格；留白+1px 细线/分隔线为主，避免卡片；圆角 0-2px 或直角。

插画（本套风格的统一语言）：每个分区可放**少量与内容相关的小插画**作点睛（≤1 个/区），
风格统一为**深橄榄 #4A5A3A 单色极简细线稿**（个别可加铜棕 #8B6F47 点睛），无填充、无彩色、
无卡通、无装饰涂鸦；更接近建筑事务所的轴测图、工业设计的草图、档案馆的图鉴线稿，
而非插画风插画。插画必须与所在分区内容相关。

相关图片（作品/系统的真实感证据图）：站点是"交付凭证"，最终展示**用你的真实界面截图（脱敏版）**；
但在**参考图阶段**，这些文案用**示意界面图/缩略图占位**，目的只是定"图放哪、多大、怎么排、气质对不对"，
不锁定图内容。示意要求：干净界面、近黑#1C1A17文字、深橄榄#4A5A3A按钮/高亮、骨白底、无 logo/无真实数据/无人像。
真实脱敏截图在业务门素材阶段替换（见 `docs/a-立项文档.md` 素材计划）。

反套路（明令禁止）：渐变、玻璃拟态、磨砂、霓虹、荧光、圆角大卡片、卡片墙、
技能条、代码背景、终端样式、假仪表盘、照片人物头像、手写体、像素字、复古科技拼贴、
花哨扁平插画、卡通吉祥物、装饰性涂鸦。
```

## 使用与判定自查

### 出图流程
1. 先贴「0. 全局风格基准」锁定气质，再逐区贴 1–9。
2. 1 分区 = 1 张横向图；想让平台评审（而非仅出图），在提示词末尾追加：
   `请同时评审：9 个分区骨架是否各不相同；配色与对比度是否符合可读性；移动端是否可行；哪些元素冗余。以设计师角度给出改进意见。`

### 出图后审查（架构门验收，对应用户在 PROJECT_STATUS 的第 2–4 项）
- **一致性**：导航/站标/配色/圆角/CTA 家族是否统一；分区节奏是否连贯；是否全部贴合"档案/卷宗"母题。
- **插画/相关图片一致性**：装饰线稿统一"深橄榄单色细线、≤1 个/区、与内容相关"；项目案例/首屏/能力区的"相关图片"在**参考图阶段为示意界面/缩略占位**（干净、近黑+深橄榄+骨白、无 logo/数据/人像）；出现彩色/卡通/装饰涂鸦即砍。
