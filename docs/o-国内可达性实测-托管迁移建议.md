## 1. 结论（一句话）

**站点托管在 GitHub Pages 上直连、前面没有国内 CDN，从国内网络访问存在 TLS 抖动与随机连接重置；这足以让"0 询单"里相当一部分归因于"访客根本没看到完整页面"，而不是商品或文案问题。**

因此在 §4 的根因排序里，**可达性排在分发与转化素材之前**——本档据此修正 `docs/n-` 的优先级。

## 3. 判读与边界（不夸大）

- **成立**：国内网络对本站的访问存在**可复现的丢包/重置**（样本内 1/5），以及 2 倍量级的 TLS 抖动（0.5 s vs 2.3 s）。
- **不成立/未证**：不能由此断定"这就是 0 询单的主因"——因为分发是否发生过（12 条存量推文发出几条）与转化素材空缺（状态行/「不接」清单）两个变量仍未排除。**本档只证可达性是根因之一，不独占归因。**
- **样本边界（重要）**：n=5、单台机器、单一网络、固定时段；**未做真机 + 手机流量复测**。按本项目既有纪律（样张≠真机），§7 的验收必须包含真机项才算过门。
- **纪律反哺**：既往上线门只验了 `200 可达`，**未验延迟分布与重置率**，所以这条缺陷一直不可见。建议在上线门验收里补一条硬断言（§6 阶段 4）。

## 5. 唯一推荐（依宪法 §26，只给一条 + 淘汰理由）

**推荐：把静态托管从 GitHub Pages 迁到国内可达的静态托管 + 自定义域走国内 CDN，GitHub Pages 保留为回退。**

淘汰方案（写明依据，不作备选）：
- **Cloudflare 免费页继续直连**：本机实测 `static.cloudflareinsights.com` 可达（0.57 s），但 CF 免费节点对中国大陆无加速，且 §2.2 的 RST 正是这种链路的典型表现——不换实质。
- **Vercel**：`a-立项文档` §5 曾列为候选；国内解析同样落到境外节点，本档不引入未实测的乐观判断，淘汰待议（若要保留须先做同口径 20 次实测）。
- **自建源站**：违反宪法 §1 精神且成本与维护超出一人产能，淘汰。

## 10. 实施记录（2026-10-22 · 前端缓解；**不改变 §5 的迁移结论**）

### 10.1 做了什么
把首屏 CSS 从外链改为**构建期内联**，落点 `site-react/scripts/prerender.mjs`（单点：壳读一次，四张页同源于它）。JS 仍外链。

**为什么这一处**：§2.2 实测的唯一失败模式是「CSS 那一个请求被重置 → 访客看到裸 HTML」。内联后样式随 HTML 同批到达，**该失败模式对首屏归零**。这不是猜测，是针对性消除单点。

**代价（如实）**：单页 HTML 由 40 kB 涨到 54–80 kB（gzip 约 +7 kB）；换来的是样式不再依赖第二次请求。老浏览器无影响（`<style>` 是最原始能力）。

### 10.2 三条前提与断言（任一不成立 build 失败，不静默降级）
| 前提 | 为什么必须成立 | 兜法 |
|---|---|---|
| CSS 内 `url()` 全为绝对 `/assets/...` | 子页在 `/writing/<slug>/`，相对路径会去文章目录下取字体 | 实测 `dist/writing/four-gates/index.html` 含 `url(/assets/noto-serif-sc-500-…woff2)`；代码里正则拦相对路径 |
| CSS 内无 `</style` | 内联即破相 | 断言 throw |
| 内联后不得残留 `rel="stylesheet"` | 防将来 vite 拆出第二个 CSS 分片时某页静默缺样式 | 断言 throw |

### 10.3 实测结果（本机 · 预览 4173 · 内网非全国）
- `npm run build` 全链路绿：`[check-content] 通过（growth 9 · now 1 · skills 7 · writing 1）`、`[fonts] 覆盖率校验通过（子集 959 / 当前渲染 866）`——**衬线子集 959 一字未增**（`scripts/fonts.mjs:40-41` 的 `stripStyle` 本就把 `<style>` 块剔出渲染面，故内联不进取字口径）。
- 四张页：`<style>`=1、`link[rel=stylesheet]`=0、`.css` 资源请求=0；体积 54,058–80,004 B。
- 运行时 computed-style（子页）：`--color-base=#f7f4ef`、`--color-ink=#1a1a1a`、`body` 底色 `rgb(247,244,239)`、h1 `33.6px` 衬线、`document.fonts.check('700 … "Noto Serif SC")`=true、woff2 实际取回 3 个。
- 运行时（首页）：h1 `43.86px`、woff2 5 个、`section` 七区齐（hero/story/cases/capability/writing/principles/contact）、横向溢出 `-15px`（即 0）、控制台 0 条。
- 负样本：见 `docs/components.md` §8 第 11 条——**其中 `</style` 分支未被独立验证**，已如实记为未验。

### 10.4 边界（别把缓解说成修复）
- 本节只消除「样式丢失」，**没有消除 §2.1 的 TLS 抖动与 RST 本身**；HTML 请求若被重置，整页依然取不到。R1 的真解决仍系于 §5 迁移 + §8 备案答复。
- 预览断言在 `localhost`，**不含全国真机链路**；站外仍须按 §7 跑 20 次取回与手机流量截图才算过门。
- 上线门应补一条硬断言（§7 已列），本档未自行修改宪法，待站主打钩。
