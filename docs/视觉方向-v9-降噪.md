# 视觉方向 v9 — 降噪（风格不动，密度减半）

> 日期：2026-10-21 · 状态：已过门（用户原话「就根据你提到这几种来，组件、排版、比例等细节同步优化，去掉AI味」）
> 前置：v8「纸墨工房」三色制全部保留；本文只规定**减法**与**同步微调**，不引入新色、新字体、新装置。

## 0. 诊断（实证）

不清爽的根因不是风格，是密度：同一信息被重复标注。实测证据（2026-10-21 dev 快照 + 样式源码）：

- 「独立系统建构者」首屏出现 2 次（Hero 眉栏 + rail 行）
- 导航系统两套并存（顶导 7 项 + 02 故事区内嵌 5 链）
- 页脚 tagline「把一团乱麻，理成能用的系统」出现 2 次（封底 slogan + footer）
- 联系区邮箱 3 个并列
- 每个区头同时挂 3 套身份装置：眉栏（档案 0X）+ 右侧大区号（meta）+ plate-rail
- 02 区尾部另有 meta 群（PLATE 02/07 · CAT · REV · BY）
- `page-num` 是无任何 CSS 规则的裸类名残留

## D1 顶导去重

- 删「01 封面」项：logo 本就是回顶链接，且首屏即封面，导航不需要指回当前位置。
- 删各项的 mono 编号前缀（`01/02…`）：编号职责归各区眉栏「档案 0X」。原「导航编号=图版号镜像」规矩废止——镜像意味着两处手工同步，正是噪音来源。
- 保留：品牌、5 项区链（故事/项目/能力/写作/规矩/联系→6 项）、在线状态、中/EN 切换。

## D2 故事区内嵌导航整组删除

- 删 right-nav 5 链 + 裸 `page-num`：与顶导职责完全重叠。
- 删区尾 meta 群（PLATE/CAT/REV/BY）：plate-rail 已承担「图版 02 · STORY」；REV/CAT 是内部工程信息，不给读者看。

## D3 Hero 眉栏/rail 去重

- rail 行去掉 role：由 `DOSSIER · 一个故事 · 独立系统建构者` 收成 `DOSSIER · 一个故事`。
- 眉栏（档案 01 · PERSONAL DOSSIER · 独立系统建构者）保留 role——全页只说一次。

## D4 区头装置三选一

- 各区 section-head 右侧大区号（meta 03/04/05/06/07）全删。编号已在眉栏。
- 保留：眉栏 tag + plate-rail（竖排书口是风格签名）。
- 全局 `.section-head .meta` 规则随之删除。

## D5 联系区与页脚去重

- 邮箱 3 → 1：默认保留 `1462882928@qq.com`（原列表首位）。**裁决点**：要换主邮箱改 `Contact.tsx` 一行即可。
- Footer 删 tagline 行（「把一团乱麻…」已在封底 slogan 出现过一次）；footer 只留脱敏声明 + 署名标。

## D6 案例卡标签（维持现状，不扩）

- rail 行 `GATE✓ · CASE/0N · 底座 · 部位`：GATE✓ 仅「已上线」盖章是 v5 既有纪律，保持。
- 不再新增任何标签层。

## D7 排版比例同步微调

- mono 微标签全站统一 `--text-xs` + letter-spacing 0.08em（rail 基准），既有偏差随删随清。
- 各区「眉栏 → 分隔线 → 大标题」的垂直节奏统一走 `.section-head` + `.rule` 共享类；Story/Principles 的自定义 rule 若与共享 rule 无差异则删自定义。
- 字号 token 不动（v8 已定 4 档标题 + hero/mega）。

## D8 去AI味清单（扫尾核对用）

禁：居中口号大区块、emoji 图标、渐变紫、圆角阴影卡片堆、一行多强调。
允：左对齐编辑式排版、单一强调色（砖红）、mono 事实行、手绘批注（v8 手层既有）。
本站基本合规，本批只核对不新增。
