## 0. 一句话气质

> **把"把一团乱麻，理成能用的系统"这句定位，用"精品咨询 / 建筑事务所 / 工业设计工作室"的克制工程气质 + 一层"个人档案/卷宗"的母题呈现——让人一眼觉得"贵"，但绝不显得"装"。**

两个字把它钉住：**克制 · 可信**。

## 1. 核心母题（本次升级的灵魂）：整站是"一份公开的个人档案 / 交付卷宗"

参考 jintao.co.uk 的 `PERSONAL DOSSIER` 手法，把全站统一成**一份编号卷宗/档案**：

- 站名副标：`PERSONAL DOSSIER · 独立系统建构者` 或 `存档 · 独立交付档案`
- 每个分区 = 一个 **档案章节**，配统一格式的眉题标签：
  - `档案 01 · 定位`
  - `档案 02 · 做过的事`
  - `档案 03 · 项目案例（卷宗）`
  - `档案 04 · 能力`
  - `档案 05 · 成长`
  - `档案 06 · 做事的规矩`
  - `档案 07 · 联系`
- 好处：这本身就是"把乱麻理成系统"的**视觉隐喻**——访客一眼看出"这是一个有档案意识、有体系的人"。且与"回调即转化"的气质高度融合。

## 2. 为什么是这套视觉（逻辑与取舍）

- 站主的经历本身就够硬（8 年政务、从零搭工业系统、SSO、真实外单已上线、一批自动化工具）——发生在"真实世界、钢筋混凝土"里。
- 用优雅的**档案/卷宗 + 克制工程感**展示它，等于在视觉上再次确认站主最擅长的能力：**把复杂、混乱的东西整理成有秩序、可运行、有据可查的系统**。
- 参考站 0xran.com(真实抓取)已是"暖白+近黑+低饱和强调"的克制极简，且用 **Astro** 实现——**证明我们这个方向既成立又可用所选技术栈做出来**。
- 对老板给"可靠、敢托付"，对技术方给"有章法、值得合作或指点"。

## 3. 配色 token（锁定；0xran 实测背书这组色板）

| 角色 | 值 | 说明 / 依据 |
|---|---|---|
| 背景 Base | `#F2EFE9`（骨白/暖灰白） | 接近 0xran 实测浅色 `#faf9f6`，偏石质感、不偏色调 |
| 文字 Ink | `#1C1A17`（近黑深灰） | 接近 0xran 实测文字 `#1f1d1b`；不用纯黑 |
| 弱文字/网格线 Line | `#8A8580`（中性灰） | 日期、说明、细线、占位虚框 |
| 主识别色 Accent | `#4A5A3A`（深橄榄绿，全站唯一识别色） | 克制；用于"档案/卷宗"识别锚点：眉题、时间轴主线、系统节点 |
| 强调色 Highlight | `#8B6F47`（铜棕/暗金） | 极少量点睛：序号 01—04、CTA、关键强调；每屏 ≤1–2 处 |

- 保持"骨白+近黑"双中性基底 + **一个深橄榄识别色** + **一点铜金点睛**。
- 未采用 0xran 的尘蓝强调——因蓝色偏"科技/程序"，我们的建筑/档案气质用**橄榄绿/铜棕**更贴（暖、有土地感、可信）。
- **禁止**渐变、玻璃拟态、荧光、低对比。

## 4. 字体

- **标题**：巨大 Serif（衬线），editorial/建筑感。中文用思源宋体（Noto Serif SC，可超粗字重）；英文概念句可用衬线或窄版显示体（参考 jintao 用 Cormorant Garamond 这类衬线）。
- **正文 / UI**：现代无衬线（Noto Sans SC / 系统黑体）。
- **档案编号 / 日期 / 数据**：等宽（IBM Plex Mono 或系统等宽）——强化"档案/工程"感（参考 jintao、0xran 的 `tabular` 等宽数字）。
- 排印密度：大留白；标题可到 viewport 极大比例（建筑感来自"敢留白、敢放大"）。
- **避免**：手写体、像素字（jintao 的 Caveat/Silkscreen 不取，会显得不克制）。

---

## 5. 布局与网格

- **严格 12-column grid**，全站对齐基线。
- **留白 + 细线**为主，卡片**尽量减少**。
- 需要区分时用：**1px 细线框 / 分隔线 / 留白 / 卷宗编号**，不用圆角大卡片。
- 圆角 **0–2px**（极轻或直角）。

## 6. 九个分区的新骨架（真实内容与顺序不变）

> 骨架各不相同（避免单调），统一在"档案/卷宗 + 工程"母题下。

### 1. 首屏定位（Hero）
- 开场宣言 + 直接进入 `精选作品 01—04`，不立即摆技能（制造"有经验的独立交付者"第一印象）。
- 案：
  - 眉题（橄榄等宽小字）：`档案 01 · PERSONAL DOSSIER · 独立系统建构者`
  - 巨型衬线主标题（中文为主）：
    > **把复杂的事情，**
    > **变成可以运行的系统。**
  - 副行（中性灰）：真实履历压缩：`8 年在真实系统里 · 工业数字化 · 全栈 · 真实交付`
  - 下方极克制入口：`精选作品 01—04 ↗`
  - 顶部小字站标：`PERSONAL DOSSIER · 独立交付档案`（可加 `ONLINE / 在线` 状态，参考 jintao）
  - 底部三个目录式纯文字入口：`独立交付 →` `业务落地 →` `边界诚实 →`

### 2. 品牌故事
- 编辑式短段，克制讲身世转折。左文字块 + 右留白（可加一个极简橄榄抽象几何线稿：截面/桥/笔，建筑感）。

### 3. 做过的事（纵向档案 / Archive）
- 一条细橄榄主线贯穿，5 个真实节点（**真实时间顺序不变**）。
- 每节点用**档案式年份排版**：等宽年份（如 `2018—2025`）+ 项目名（衬线）+ 一行说明。像档案馆年鉴条目，不装饰、无假 KPI。

### 4. 项目案例（建筑事务所 Case Study / 卷宗）
- 每个案例一条 **study/卷宗**，带铜金编号 `01—04`（**工程用车助手第 1 位**）+ 案例名（衬线大标题）+ "问题 → 我做了什么"（灰）+ 技术栈（橄榄小字）。
- 右侧一个**留白占位示意槽**（4:3 细灰虚框 + 极淡工程线稿，不画真实截图）。
- **新增（参考 jintao）**：每条案例左上角加**状态徽章**——`已上线` / `内部系统` / `开发中`，透明可信（用小圆点+小字，克制，不做成彩色大徽章）。

### 5. 四梯队能力地图
- 四层"系统层级"纵向结构（独立交付墨黑标题 / 业务落地 / 工具提效橄榄 / 边界诚实灰），层间细橄榄分隔线。能力是"被组织进系统"，不是并列标签。

### 6. 成长记录（月度档案索引）
- 编辑式月度条目：月份（等宽衬线）+ 一句收获 + 橄榄小箭头；左侧留白引言"给自己一个每月进步的交代"。参考 jintao 的"笔记志"每月档案 + 0xran 的日期+tag。

### 7. 做事的规矩（系统流程图）
- 四门禁（立项→架构→业务→上线）连成一条**带递进箭头的系统线**，外加底部纪律小字（SSOT）。用橄榄细线把四门禁串成"一个整体系统"，而非零散条目。

### 8. 联系交流
- 极简居中、超大留白。"聊得来，就一起做事"，下行微信号+邮箱，一个铜棕实心按钮"加微信聊聊"。
- **新增（参考 jintao 匿名转化手法）**：在"索取详细成果/履历"处加一句专业引导——`雇主与过程细节对公开版隐去 · 详询索取 ↘`，把诚实边界变成询盘入口。

### 9. 底部
- 极简：一行极小灰字匿名声明 + 右侧橄榄小字定位句 + 一条极细橄榄分隔线。

## 7. 动效（克制到几乎看不见）

- 只保留：**`fade-up` 轻入场**（位移小、速度慢，参考 0xran）、轻微 hover（细线变橄榄/箭头位移）、数字/年份淡变。
- **尊重 `prefers-reduced-motion`**：关闭全部动效，内容全量显示。
- **禁止**：满屏动效、粒子、视差炫技。

## 8. 明确不做（反套路清单）

- ❌ 渐变、玻璃拟态、磨砂、霓虹、荧光

## 9. 落地实现原则（保持轻量）

- 纯静态单页：Astro + 原生 CSS（token）+ Markdown；无后端/数据库/登录。
- 配色/字体/间距全走 `src/styles/` token；细线/时间轴/卷宗编号/连接线＝代码原生（CSS/SVG），不依赖图片素材。
- 唯一素材＝极轻微纸张/石质噪点（可省）+ 案例占位示意槽。
- 成长记录 md 月度一更（0xran 用 Astro 手搓证实该路线可行）。
